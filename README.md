# PINBALL

## Description

Hemos creado un juego de pinball 2D desarrollado en C++ con raylib (gráficos, audio y entrada) y Box2D (motor de físicas). el proyecto tiene como objetivo: entender cómo se simula la física en el mundo de los videojuegos, donde aprendemos de los conceptos fundamentales y a ajustar parametros fisicos para crear esa simulación física como gravedad, colisiones, densidad, rebotes, fricción, fuerzas, etc, ademas de comprender cómo se unen cuerpos entre sí, como los flippers o el muelle de lanzamiento, y el funcionamiento general del motor de físicas Box2D.

## Key Features

 - Físicas realistas: Simulación precisa de la gravedad, rebotes y fricción aplicadas a la bola mediante Box2D.
 - Mecánicas de Pinball: Implementación de uniones físicas para articular los flippers y simular la tensión del muelle del lanzador de bolas.
 - Integración de uso de la biblioteca raylib para el renderizado eficiente en 2D, reproducción de audio,etc. 
 - Modo debug integrado para visualizar los colliders y fuerzas en tiempo real
